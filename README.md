# にじのね保育園 — Growvia for kizz サービス体験デモ

架空の保育園を舞台に、ホームページ構築・問い合わせ自動チャットボット・社内botの使い心地を見せる静的サイトです。ビルドやパッケージのインストールは不要です。

## 表示する

このディレクトリで以下を実行します。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8765/` を開きます。静的ホスティングでは、このディレクトリをそのまま配信できます。

## 体験できること

- 園の想い・年齢別の1日・園の基本情報を、スマートフォンとPCで閲覧。
- 問い合わせbotに質問例または文字を入力して、登録済みの案内を確認。
- 会話内のボタンから見学体験へ進み、年齢・希望時間の確認画面を表示。
- 職員向けbotで手順を確認し、参照元となる4つの架空マニュアルを開く。
- 実際のAIデモ、GrowviaのLINE相談窓口へ移動。

## 動作の範囲

ページ内のbotは入力のキーワードに対応する回答例を表示する体験サンプルです。生成AIへのAPI接続はありません。未知の質問には、担当者への確認が必要な旨を表示します。

入力はブラウザ内で処理し、保存・送信しません。見学の体験フォームも予約を確定しません。社内botの資料はこの公開サイト用に作成した架空資料で、認証・実際の社内資料検索・アップロード機能はありません。本番導入には認証や資料の公開範囲、問い合わせの引き継ぎ方法などを別途設計します。

実際のAIは既存の外部デモ `https://udify.app/chatbot/uLRzsv72qvWlhZpP`、導入相談は `https://lin.ee/o4N95GI` を使用しています。ユーザーが外部リンクを開くと、そのサービスに移動します。入力を自動で引き渡す機能はありません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本文・見学体験フォーム・外部リンク |
| `styles/site.css` | サイト全体のデザイン・レスポンシブ対応 |
| `styles/bots.css` | チャット・資料ビューアのデザイン |
| `scripts/site.js` | メニュー・年齢切替・見学体験・bot導線 |
| `scripts/demo-bots.js` | 回答例・架空マニュアル・チャット操作 |
| `logo.png` | 既存ロゴ |
| `assets/nursery-garden.webp` | メインビジュアル（Web配信用） |
| `assets/README.md` | 画像生成方法と最終プロンプト |

園の設定を変える場合は、`index.html` の基本情報、`scripts/site.js` の時間帯、`scripts/demo-bots.js` の回答・マニュアルも同じ内容にそろえてください。

## 操作・アクセシビリティ

- メニューは開閉状態を通知し、Escapeで閉じられます。
- 年齢別タブは左右矢印・Home・Endキーでも切り替えられます。
- 見学・資料ビューアはネイティブdialogを使い、Escapeで閉じ、操作元へフォーカスを戻します。
- チャットは日本語入力の変換確定中に送信しません。回答は読み上げ用の通知領域にも表示します。
- 動きを減らす端末設定に対応します。
- JavaScriptが無効な場合も園の紹介と外部リンクを閲覧できます。
